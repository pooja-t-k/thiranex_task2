# 👥 Customer Segmentation Dashboard

An interactive **Customer Segmentation Dashboard** built using Python and Streamlit to analyze customer behavior, demographics, and purchasing patterns using **K-Means Clustering**.

## 📌 Project Overview

Customer segmentation is the process of dividing customers into groups based on similar characteristics and purchasing behavior.

This project uses customer attributes such as:

- Age
- Annual Income
- Spending Score
- Purchase Frequency
- Total Purchase Amount
- Gender

The dashboard helps identify different customer groups and provides meaningful insights that can support targeted marketing and business decision-making.

## 🎯 Objectives

- Segment customers using machine learning
- Analyze customer purchasing behavior
- Understand demographic patterns
- Visualize customer segments
- Evaluate clustering performance
- Generate useful business insights

## 🚀 Key Features

### 👥 Customer Segmentation
Uses **K-Means Clustering** to group customers with similar characteristics.

### 🎛️ Interactive Clustering
Users can:

- Select features for clustering
- Adjust the number of customer segments
- Explore different customer attributes

### 📊 Customer Analytics
Analyze:

- Customer distribution
- Spending behavior
- Purchase frequency
- Purchase amount
- Age distribution
- Gender distribution

### 📈 Data Visualization
The dashboard provides interactive charts to understand customer segments and relationships between different customer attributes.

### 📋 Segment Characteristics
Displays important information for each customer segment, including:

- Number of customers
- Average age
- Average income
- Average spending score
- Average purchase frequency
- Average purchase amount

### 💡 Business Insights
Identifies important customer groups such as:

- Highest spending segment
- Most frequent customers
- Highest-value segment

### 🎯 Clustering Evaluation
Uses the **Silhouette Score** to evaluate the quality of the customer clusters.

## 🧠 Machine Learning Approach

### K-Means Clustering

K-Means is an **unsupervised machine learning algorithm** used to group similar customers into different clusters.
